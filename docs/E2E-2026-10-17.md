## Falhas encontradas e corrigidas

1. `appendLiveRun()` inseria mensagens temporárias diretamente em `#messages`. A renderização final só substitui `#messageList`, deixando um placeholder antigo. Corrigido para o mesmo contêiner paginado.
2. O DOM do ChatGPT às vezes apresenta o novo Markdown do assistente antes de criar seu contêiner final. O observador Beta lia a mensagem anterior. Agora considera o Markdown provisório somente quando a geração está ativa e ele não pertence ao contêiner antigo; a observação não lê menus ou texto genérico da página.
3. Os scripts de teste de texto, imagem e continuidade consideravam a Task pronta assim que o painel de chat estivesse visível. Em um projeto aberto, podiam enviar para a Task anterior. Corrigido para esperar a mudança do ID da Task. A fixture de paginação já adotava essa proteção.
4. O teste de paginação usa uma Task de fixture criada pela UI e povoada para teste no mesmo SQLite; valida a navegação exclusivamente por botões e remove a Task e seus eventos depois. Não há cópia do histórico em outro banco.

## Reprodução

Iniciar o app em modo de depuração, na raiz do projeto:

```powershell
$env:ORDAX_DESKTOP_DEBUG = '1'
npm start
```

Em outro terminal, executar um gate por vez (o lock `e2e.lock` impede concorrência):

```powershell
npm run test:live:text
npm run test:live:stream
$env:ORDAX_E2E_MODE = 'beta'
npm run test:live:stream
Remove-Item Env:ORDAX_E2E_MODE
npm run test:live:continuity
npm run test:live:image
npm run test:live:history
```

Para `test:live:restart`, encerrar e reabrir o Electron entre os comandos de imagem e restart. O teste verifica a imagem persistida mais recente.

## Gates ainda não homologados

- Interface visual em diferentes tamanhos de janela, especialmente mobile/tablet.
- Troca **automática** real após 24 respostas concluídas (a política está coberta por testes locais, mas não por este E2E).
- Estabilidade prolongada e recuperação sob falhas de rede/alta carga.
- Teste E2E sobre o executável portátil empacotado e assinado (os E2E desta rodada rodaram o código-fonte).
- Git remoto: este repositório local ainda não tem `origin` configurado.

Nenhum teste desta rodada implicou bypass de autenticação, API privada para enviar prompts ou reenvio automático após falha.
